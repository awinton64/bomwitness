# Pipeline layout

This directory mirrors the stage layout of the SafeIoT supply-chain pipeline
(`1_analysis_object`, `2_preprocess`, `3_security_analysis`, `4_analysis_output`, `pipeline_harness`), with
one subdirectory per stage named `bomwitness`. Start at
[`pipeline_harness/bomwitness/README.md`](pipeline_harness/bomwitness/README.md).
